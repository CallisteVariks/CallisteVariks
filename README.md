## About

I work across **data, analytics, software engineering, and app development**.

My GitHub is a mix of practical tools, experiments, side projects, and ideas that eventually became code, usually because I wanted something that didn't quite exist the way I wanted it.

```text
> turn messy data into useful systems
> build apps around problems I actually have
> learn by making things
> occasionally over-engineer something for fun
```

## What I build
### 📱 Apps
I'm building mobile apps for different everyday use cases, including:
- movie tracking
- personal book and library management
- Sudoku
- expense tracking
- randomizers and decision tools
- small utilities and experiments
  
Some solve a problem I have.

Some exist because I wanted to build my own version.
### 🧩 Data, tools & experiments
I also work on:
- data engineering and analytics
- developer tools
- visual interfaces
- Markdown and CSS experiments
- small utilities
- whatever problem looks interesting next
